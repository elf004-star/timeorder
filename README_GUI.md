# 井段状态预测模型训练系统 - GUI版本

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

或者手动安装：

```bash
pip install pandas numpy scikit-learn lightgbm matplotlib seaborn
```

### 2. 启动GUI程序

```bash
python train_model_gui.py
```

### 3. 使用界面

程序启动后会显示一个图形界面，分为左右两部分：

#### 左侧控制面板

1. **数据文件选择**
   - 默认使用 `data001.csv`
   - 点击"浏览..."按钮选择其他CSV文件

2. **数据集划分**
   - 测试集比例：滑动条调整（默认0.2）
   - 验证集比例：滑动条调整（默认0.1）
   - 自动按井为单位进行划分

3. **超参数配置**
   - 学习率：控制模型学习速度（默认0.05）
   - 叶子节点数：树的复杂度（默认31）
   - 最大深度：树的最大深度（默认7）
   - 训练轮数：最大迭代次数（默认500）
   - 早停轮数：防止过拟合（默认50）
   - 特征/样本采样率：控制随机性

4. **开始训练**
   - 点击"开始训练"按钮启动训练过程
   - 查看进度条和状态信息

#### 右侧显示面板（三个标签页）

1. **训练监控**
   - 实时显示训练和验证损失曲线
   - 蓝色：训练集损失
   - 红色：验证集损失

2. **训练日志**
   - 显示详细的训练过程日志
   - 包括数据加载、特征工程、训练进度等

3. **训练结果**
   - 显示测试集评估结果
   - 包括准确率、F1分数等指标
   - 展示规则修正前后的对比

## 主要功能

✓ **直观的图形界面** - 无需编写代码或命令行操作  
✓ **灵活的文件选择** - 支持选择任意CSV数据文件  
✓ **可调的数据划分** - 自定义训练/验证/测试集比例  
✓ **超参数配置** - 实时调整所有关键超参数  
✓ **实时监控** - 动态显示训练损失曲线  
✓ **详细日志** - 完整记录训练的每个步骤  
✓ **自动保存** - 训练完成后自动保存模型  

## 输出文件

训练完成后会生成：

- `well_status_model.txt` - 训练好的LightGBM模型

## 数据格式要求

CSV文件必须包含以下列：

- `序号` - 序号
- `转换后JH` - 井号
- `JX` - 井斜角
- `dy➗dx` - 井斜角变化率
- `status` - 状态标签（0/1/2/3）

## 状态说明

- 0: 直井段 (Vertical)
- 1: 造斜段 (Build-up)
- 2: 稳斜段 (Hold)
- 3: 降斜段 (Drop-off)

## 超参数调优建议

### 过拟合（训练损失低，验证损失高）
- 减小叶子节点数和最大深度
- 增加最小样本数
- 降低特征/样本采样率

### 欠拟合（训练和验证损失都高）
- 增加叶子节点数和最大深度
- 减小最小样本数
- 增加训练轮数

### 训练速度太慢
- 增加学习率
- 减小叶子节点数
- 减小训练轮数

## 注意事项

1. 训练过程在独立线程中运行，不会冻结界面
2. 训练时可以查看实时日志和损失曲线
3. 请勿在训练过程中关闭窗口
4. 首次训练建议使用默认参数
