界面元素说明:
─────────────────────────────────────────────────────────────────────────────

左侧控制面板:
  1. 数据文件选择区
     • 显示当前选择的文件
     • [浏览] 按钮打开文件选择对话框
  
  2. 数据集划分区
     • 滑动条调整测试集比例 (0.1-0.4)
     • 滑动条调整验证集比例 (0.05-0.3)
     • 右侧显示当前数值
  
  3. 模型超参数区
     • 8个可配置的超参数
     • 输入框直接输入数值
  
  4. 训练控制区
     • [开始训练] 按钮启动训练
     • 进度条显示训练进度
     • 状态标签显示当前状态

右侧显示面板:
  三个标签页可切换:
  
  1. [训练监控] 标签页
     • 实时绘制训练和验证损失曲线
     • 蓝色实线: 训练集损失
     • 红色虚线: 验证集损失
     • 横轴: 迭代次数
     • 纵轴: 损失值 (Log Loss)
  
  2. [训练日志] 标签页
     • 滚动文本框
     • 显示详细的训练过程信息
     • 自动滚动到最新内容
  
  3. [训练结果] 标签页
     • 显示最终评估结果
     • 包括准确率、F1分数等指标

使用流程:
─────────────────────────────────────────────────────────────────────────────

1. 启动程序
   python train_model_gui.py

2. 配置参数 (可选)
   • 选择数据文件
   • 调整数据集划分比例
   • 修改超参数

3. 开始训练
   • 点击 [开始训练] 按钮

4. 观察训练
   • 切换到 [训练监控] 查看曲线
   • 切换到 [训练日志] 查看详情

5. 查看结果
   • 训练完成后切换到 [训练结果]
   • 模型自动保存

6. 完成
   • 模型文件: well_status_model.txt

关键特性:
─────────────────────────────────────────────────────────────────────────────

✓ 界面不卡顿 - 训练在独立线程运行
✓ 实时更新 - 损失曲线动态刷新
✓ 易于使用 - 无需编程知识
✓ 参数灵活 - 所有参数可调整
✓ 日志完整 - 记录所有训练信息
✓ 自动保存 - 训练完成自动保存模型

提示:
─────────────────────────────────────────────────────────────────────────────

• 首次使用建议保持默认参数
• 训练过程中可以切换标签页查看不同信息
• 如果损失曲线不收敛，尝试调整学习率
• 过拟合时减小模型复杂度(叶子节点数、最大深度)
• 欠拟合时增加模型复杂度
